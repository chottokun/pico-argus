# Pico Cognitive MCP サーバー 応用解析＆活用事例ガイド (Use Cases)

本ドキュメントでは、Pico システムに搭載された `cognitive-surveillance` MCP サーバー（全11ツール）を活用して実現できる、高度なアクティブセンシング・VLMマルチモーダル解析・長期記憶連携の具体的な応用例と実践シナリオを解説します。

---

## 🚀 1. 室内全方位パノラマ環境調査 ＆ アイテムインベントリ自動構築
### 💡 概要
部屋の東西南北（または正面・左右・上部）へカメラを自動制御し、YOLO物体検出と VLM (視覚言語モデル) を組み合わせることで、室内の配置・家具・家電・備品の自動インベントリ（目録）を Wiki データベースへ保存します。

### 🛠️ 使用する MCP ツール
- `conduct_room_survey`: 4方向へのパノラマスキャン実行
- `analyze_crop_image`: VLM による視覚言語モデル深層シーン解釈
- `write_wiki`: インベントリ記録の FTS5 長期記憶（`wiki.db`）への永続化

### 📋 実行例・活用シナリオ
- **お出かけ前の室内点検**: 窓の閉め忘れ、照明の点灯状態、電気機器の切り忘れをパノラマスキャンで一括チェック。
- **遺失物・模様替え履歴の管理**: 「鍵や財布をどこに置いたか」「部屋の模様替え前の状態」を画像とテキストで自動記録。

---

## 🎯 2. 特定オブジェクト・人物の自動物理PTZロックオン追尾
### 💡 概要
特定の人物（`person`）や特定の持ち物（`suitcase`, `handbag` 等）が画面内に現れた際、PIDサーボループによってカメラレンズを物理的に駆動し、常にオブジェクトを画面中央（スクエア）へ自動追従・補正し続けます。

### 🛠️ 使用する MCP ツール
- `set_tracking_target`: 追尾ターゲット（クラス名またはトラックID）の動的指定・自動再捕捉
- `get_active_tracks`: リアルタイム空間座標・信頼度・バウンディングボックスの監視
- `get_perception_status`: 追尾FPSおよびイベントログの健康状態取得

### 📋 実行例・活用シナリオ
- **室内見守り・自動フォロー**: 人物が部屋の中を移動しても、カメラが自動的に向きを変えて追従。
- **特定物品の盗難・動体監視**: 貴重品やバッグが持ち去られそうになった際、即座に追尾してログを記録。

---

## 🔍 3. アクティブ・高解像度クロップ VLM 深層精査
### 💡 概要
部屋の遠くにある小さな物体や気になるエリアを対象とし、YOLO BBOX でトリミング（クロップ）した高解像度画像を VLM (Gemma4 Vision 等) に入力して、「何が置いてあるか」「どのような状態か」を精密に言語解釈させます。

### 🛠️ 使用する MCP ツール
- `get_active_tracks`: 画面内に映る物体のトラックID一覧を取得
- `analyze_crop_image`: 特定トラックID指定（またはクラス指定）でのズームクロップ VLM 解釈

### 📋 実行例・活用シナリオ
- **細部の状態確認**: 「デスク上のマグカップの中身は入っているか」「書類やノートが開かれたままか」をズームクロップ視覚解釈。
- **遠隔診断**: 遠くにある家電のランプ表示やスイッチ状態をテキストで解釈。

---

## 🧠 4. 過去の記憶想起と環境変化の自動検知 (Memory & Event Loop)
### 💡 概要
過去に記録した Wiki 記憶を FTS5 Trigram 全文検索し、「前回の調査時と比べて何が新しく増えたか」「位置が変わったか」をエージェントが自律比較・分析します。

### 🛠️ 使用する MCP ツール
- `search_wiki`: 過去の調査記録・設置ルール・注意点の想起
- `configure_event_filter`: 新規オブジェクト出現 (`NEW_OBJECT`) や変化イベントの感度調整
- `write_wiki`: 差分や新たな発見の追加記録

### 📋 実行例・活用シナリオ
- **不在時の防犯・変化検知**: 自宅を空けていた間に「新しく持ち込まれた物」「移動された家具」を自動識別。
- **文脈を考慮した会話応答**: ユーザーからの「最後にハサミを見たのはどこ？」という問いに過去の記憶とリアルタイム視覚を照合して回答。

---

## ⚙️ 5. ギア遊び誤差ゼロの物理原点自動校正 (Self-Healing Alignment)
### 💡 概要
外部の干渉や長時間のPID追尾運動によってカメラの物理的な角度推測が狂った際、物理左下限界壁へのブラインド突き当てと一方向正確復帰を行い、真の正面ド真ん中原点 `(0, 0)` へ自律復元します。

### 🛠️ 使用する MCP ツール
- `calibrate_home`: バックラッシュ相殺型・自動物理ホーム校正
- `move_camera`: 中心原点復帰 (`pan=0, tilt=0`)

### 📋 実行例・活用シナリオ
- **定期メンテナンス**: 追尾終了後や夜間に自動で物理原点校正を実行し、累積運動誤差を完全にリセット。

## 📊 MCP ツール一覧と推奨連携パターン

| アクションシナリオ | 主な連携 MCP ツール | 期待される効果 |
|---|---|---|
| **定期環境調査** | `conduct_room_survey` ➔ `analyze_crop_image` ➔ `write_wiki` | パノラマスキャンから視覚言語化、Wiki蓄積まで自動完遂 |
| **人物・ペット見守り** | `set_tracking_target` ➔ `get_perception_status` | リアルタイムで対象を追従し健康状態を監視 |
| **アイテム探索・想起** | `search_wiki` ➔ `get_active_tracks` ➔ `analyze_crop_image` | 過去の記憶と現在の映像を照合し発見・報告 |
| **物理軸メンテナンス** | `calibrate_home` ➔ `move_camera` | ギア遊び誤差のない正確な原点姿勢を常に維持 |
